# Project hub

Last updated: 2026-11-02

The hub is the one place Leon and every agent read to see what NRL Sim is, what's
in it and what's next. Each page is short and plain. Anything not decided yet is
marked **Open** with its question.

- [Overview](overview.md): what the game is, who it's for, how to play it and where
  things stand.
- [Features](features.md): what's in the game today, and what was added recently.
- [Roadmap](roadmap.md): Now, Next, Later, and ideas still being discussed.
- [Marketing](marketing.md): name, store copy, pricing, payments, and the engagement
  and launch plumbing (hosting, push, analytics, pop-ups, email, privacy).

## Keeping it current

Update features.md and roadmap.md in the same PR as the change. A PR that changes
the game adds a line to features.md's **Recently added** (and moves or removes its
roadmap line if it had one). Every claim should trace to the repo, a merged PR, an
open issue or a decision Leon has written down; link the PR, not a ticket number.
