Counts shown here are raw. The standard report uses its own written-orientation metrics and scales the late-legs stretch to five minutes. Slot counts include the existing stand-in role when the regular kicker was sin-binned. The linked-alternate columns trace the feature’s last-tackle selection through the actual five-eighth kick.

## Reproducing the observations

The sidecar started from clean simulation commit `79417a38`. Apply [the observer patch](observation.patch) to a separate checkout and run `NRL_HALVES_OBSERVATIONS=/tmp/observations.jsonl npm run balance -- --plan /path/to/plan.json`. This records the actual side, player, slot, tackle number and strike, as well as the stages of each recorded ordinary dummy-half distribution. The [observation data](observations.jsonl.gz) contains every sampled match. [Observation harness aggregates](observer-results.jsonl) match every gameplay field in the clean harness output.
